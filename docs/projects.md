## PS5 runtime checks

The local package has the PS5 finalized-image header, `FIH`. Its embedded plaintext metadata identifies title `PPSA38500` and content version `01.002.001`. The first checks read the package headers and manifest and used synthetic runtime inputs. The follow-up streamed files from the completed package. [Package format](https://github.com/SvenGDK/LibProsperoPKG/blob/main/docs/ps5-pkg-format.md)

| Project | Revision | Local result |
|---|---|---|
| [KytyPS5](https://github.com/KytyPS5/KytyPS5/tree/61db2f8874d4a94fd2908a87cefa973ddc48ef6e) | Official Linux release `61db2f8` | The archive matched its published SHA-256 and the emulator started in Fedora Linux 45 Toolbox. It accepts a game directory, an ELF, or a ZArchive. It rejected a synthetic `FIH` file and booted the real title through a read-only FUSE game directory. [PS5 run](benchmarks/gmankab.md#ps5-kytyps5-startup) |
| [AnyPS5](https://github.com/boykopovar/AnyPS5/tree/978eb901961fcb6e8f4bd6bbc15ac29e72c4ef42) | Native relinker-only build `978eb901` | Built with Clang, Ninja, and Kache in the Fedora Linux 45 Toolbox. All 1,145 CTest tests passed, including Linux entry-point and Intel instruction-conversion tests. The CLI identified the synthetic `FIH` file and requested an extracted ELF. |

KytyPS5's read-only package-mount proposal closed unmerged. Its streaming helper passed the upstream sparse-file fixture. The real package needed larger bounds for a 50.4 MB NAPS table and 2.36 million compressed-block records. With those bounds and a local FUSE adapter, KytyPS5 could read the game directory in place. The helper retained its existing package validation. [Package mount PR](https://github.com/KytyPS5/KytyPS5/pull/1007)

A report for `PPSA38500` on Arch Linux with an RX 6800 XT reached the menu and then crashed after accepting the terms. That report used an AMD CPU. [Linux compatibility report](https://github.com/KytyPS5/KytyPS5/issues/2570)

AnyPS5 relinks PS5 ELF executables against reimplemented libraries. The report for the same `01.002.001` build describes shader preparation stalls in AGC submissions. The Xeon E5-2670 v3 has AVX2 and lacks SSE4a. The local Intel conversion test passed with synthetic input. The title later reached shader registration on this CPU. [AnyPS5 input and CPU requirements](https://github.com/boykopovar/AnyPS5/blob/978eb901961fcb6e8f4bd6bbc15ac29e72c4ef42/docs/user/USAGE.md) · [Shader preparation report](https://github.com/boykopovar/AnyPS5/issues/27705)

The follow-up Linux native dry run of the actual PS5 title stopped during `--to-intel` conversion. The reported branch target follows three-byte `CLZERO`, which needs extra space for a trampoline. Applying the existing movable-instruction fix to AnyPS5 `4243438` let the dry run finish with the executable and two bundled modules. The focused AMD instruction converter suite passed. An actual relink then emitted a 214.5 MB Linux x86-64 ELF and both bundled modules. REA inspected the ELF interpreter and all 56 direct dynamic dependencies. The isolated dynamic-loader check resolved the dependencies with the official AnyPS5 `v0.1.5` Linux library archive after verifying its published SHA-256. The relinked title created a 1280×720 Wayland Vulkan swapchain on the RX 6800 and began shader registration. In the REA-captured startup run, it aborted after about 38 seconds when a fixed mapping overlapped a guest reservation. The error and addresses match the upstream report. The kernel logged no GPU reset. [Matching issue](https://github.com/boykopovar/AnyPS5/issues/27525) · [Candidate PR](https://github.com/boykopovar/AnyPS5/pull/27543) [AnyPS5 PR #27560](https://github.com/boykopovar/AnyPS5/pull/27560)

A full AnyPS5 runtime build with #27543 still aborted at the same overlap. A host stack trace identified `sceKernelReserveVirtualRange`. Adding #27563 allowed the 13 MiB fixed subreservation and the subsequent direct mapping on Fedora Linux 45. The run reached 7,585 shader cache writes before the 125-second test cap. AMDGPU process counters showed no increase in graphics or compute engine time in the 84-second sample after the reservation passed. The run had no verified rendered gameplay. [Mapping PR #27543](https://github.com/boykopovar/AnyPS5/pull/27543) · [Nested reservation PR #27563](https://github.com/boykopovar/AnyPS5/pull/27563)

## PS5 and Xbox storage comparison

The 201.64 GiB PS5 package and Xbox working directory reside on the same Btrfs volume with `compress=zstd:8`. Btrfs applies compression to extents. `compsize` measured a physical-to-uncompressed extent ratio of about 100.0% for the PS5 package and 99.8% for the Xbox directory.

A read-only view of the PS5 package exposed 198 files. The Xbox working directory contained 109 files. Seventy-five PS5 files shared an Xbox basename, and only one matched by size and SHA-256. It was a one-byte alignment marker. This comparison checked whole logical files. It leaves partial-block overlap in the raw package unmeasured. The package view avoided extracting another copy, and the comparison wrote no data to either build.
