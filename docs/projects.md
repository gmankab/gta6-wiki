## CGBJ source checks

JordanFromIT’s CGBJ-VIctory repository was public with an active `integration` branch. GitHub and its source archive endpoint returned 404 on November 26. Software Heritage's visit found no snapshot. The project reported a 3.7 FPS median in the world on an RX 7900 XTX with stock Proton Experimental on CachyOS. Its exact build remains untested here. [Original repository](https://github.com/JordanFromIT/CGBJ-VIctory) · [Contemporary project record](https://gtapcport.org/cgbj-gta-6)

The public `cgbj-reupload` points to codec_d’s Cool Fox commit `f4b48ad766ddbec1a1867022cd42f7645b0dd55e`. The source tree in the archive tagged `cgbj-pareto-residency` has the identical Git tree ID, `832b1ea59576e5e2688d49c2530b67f0efae43bc`. The public `cgbj-fork` has separate Cool Fox-derived changes for Windows. At the time of the check, GitHub listed 33 stars, 91 contributors and one PR for `cgbj-reupload`, and 10 stars, 92 contributors and no PRs for `cgbj-fork`. Contributor counts include inherited history. [Reupload](https://github.com/cputroll/cgbj-reupload) · [Tagged archive](https://github.com/Guernica4u/GTA6-PC-Port-Archive/tree/cgbj-pareto-residency/cool-fox) · [Windows derivative](https://github.com/Pavl3000/cgbj-fork)

The consolidated Victory repository mirrors the same reupload commit as `cgbj-reupload`. The branch name follows the public source used for the mirror. [GitHub](https://github.com/gmankab/victory/tree/cgbj-reupload) · [GTAHub](https://git.gtahub.st/gmanka/victory/src/branch/cgbj-reupload) · [Disroot](https://git.disroot.org/gmanka/victory/src/branch/cgbj-reupload)

## Published branches

- [gmankab/victory](https://github.com/gmankab/victory) is the canonical public Victory development fork. It was renamed from `gmankab/marvisak-victory`. [Tested main snapshot at `d56316bb`](https://github.com/gmankab/victory/commit/d56316bb283495181651a7528b6f0d9c625f32e2).
- [Disroot mirror](https://git.disroot.org/gmanka/victory) had 141 branches at the November 26 snapshot. `main` and `cool_fox` matched GitHub. The mirror includes original PR branches, local integration refs and distinct experimental test branches. The first mirror pass added 136 branches and updated existing refs as needed. The [branch inventory](../data/branches.csv) records the full commit ID on each public remote.
- [GTAHub Victory fork](https://git.gtahub.st/gmanka/victory) consolidates the public GitHub and Disroot branch tips and additional Victory source refs. The other tested families have their own forks. [GTAHub fork and branch inventory](gtahub.md)
- [cool_fox](https://github.com/gmankab/victory/tree/cool_fox) preserves the original checkout’s Git history. Its first fork work follows `avatarmanz/VIctory-7900XTX` commit `0a43566`. GitHub stopped resolving the original `codec-d/cool_fox` after it was fetched. [Disroot branch](https://git.disroot.org/gmanka/victory/src/branch/cool_fox)
- [gmankab/fxceless-victory](https://github.com/gmankab/fxceless-victory) and [gmankab/zslayerhq-victory](https://github.com/gmankab/zslayerhq-victory) are older submission forks. Their historical PRs retain their original head repositories. The first published Fxceless run used `6fb11d7`; the metadata rebase used `617416b`.
- [gmankab/leonida](https://github.com/gmankab/leonida) is the public Leonida contribution fork, formerly `leonida-contrib` and `ubiquitarianism-leonida`. The original backup is private. [Flatpak packaging repository](https://github.com/gmanka-flatpaks/io.github.marvisak.victory)
